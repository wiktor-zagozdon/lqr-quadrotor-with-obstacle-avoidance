# LQR Quadrotor Control with Obstacle Avoidance

This repository contains the MATLAB simulation framework and source code for an autonomous quadrotor utilizing Linear Quadratic Regulator (LQR) control and dynamic obstacle avoidance.

This project was developed as a Master's Thesis at the **Warsaw University of Technology (Politechnika Warszawska)** under the **Faculty of Power and Aeronautical Engineering (MEiL)**.

## How to Run
1. Open MATLAB and navigate to this project directory.
2. Run `aa_dron_LQR.m` to initialize the simulation and generate the flight data.
3. Run `environ.m` to visualize the flight.
4. Run `plots.m` to generate the fligth data record graphs.
5. You can modify various parameters and run a new simulation.
